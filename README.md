# JCB Work Management & Billing

Offline-first Flutter app + React developer admin portal on Firebase.

| Folder | What |
|--------|------|
| `mobile/` | Flutter app (Android only) |
| `admin/` | React + Vite + TS developer admin portal |
| `firebase/` | Firebase config, Firestore rules & indexes, Cloud Functions |
| `docs/` | ADRs, product decisions, backlog, conventions |

Start with `docs/backlog.md` (sprint board + blockers) and `docs/conventions.md` (commands).
